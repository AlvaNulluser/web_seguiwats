Política de Privacidad de Seguiwats

Última actualización: 19 de Septiembre de 2026 • Versión: 2.4 Enterprise • Google OAuth & Meta Cloud API Verified

01. Introducción y Principio de Privacidad

En Seguiwats ("nosotros", "nuestro" o "la Plataforma"), valoramos y respetamos profundamente la confidencialidad de la información de nuestros clientes comerciales y de sus respectivos contactos y prospectos de ventas.

Seguiwats es un asistente de seguimiento comercial operado bajo los principios de "Privacy by Design" y "Zero Redundant Storage". Nuestra arquitectura opera con Google Calendar como única fuente de la verdad, lo que significa que no creamos ni mantenemos bases de datos relacionales intermedias para almacenar los contactos o el historial comercial de sus clientes.

02. Divulgación de Uso Limitado de Google API (Limited Use Disclosure)

// DECLARACIÓN OFICIAL OBLIGATORIA (INGLÉS)

"Seguiwats' use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements."

// TRADUCCIÓN OFICIAL (ESPAÑOL)

"El uso y la transferencia a cualquier otra aplicación por parte de Seguiwats de la información recibida a través de las APIs de Google se ajustará estrictamente a la Política de Datos de Usuario de los Servicios de API de Google, incluidos los requisitos de Uso Limitado."

Seguiwats no utiliza bajo ninguna circunstancia datos obtenidos mediante las APIs de Google para:

  • ✕ Publicidad personalizada, segmentación comercial ni retargeting.
  • ✕ Venta, cesión o alquiler a intermediarios o corredores de datos (data brokers).
  • ✕ Entrenamiento o reentrenamiento de modelos fundacionales de lenguaje o inteligencia artificial generalizada (LLMs).

03. Alcances de Google Calendar API Solicitados y Justificación Técnica

Al autenticar su cuenta de Google mediante OAuth 2.0, solicitamos exclusivamente los permisos mínimos indispensables para la funcionalidad del asistente:

https://www.googleapis.com/auth/calendar.events Scope Sensible

Propósito técnico: Permite a Seguiwats crear eventos de seguimiento cuando el asesor envía un audio o texto por WhatsApp (ej. "Llamar a Juan el martes a las 11:00"), consultar los eventos agendados para confeccionar el resumen diario matutino de las 9:00 AM, y actualizar o borrar el evento cuando se declara el seguimiento como cerrado.

https://www.googleapis.com/auth/calendar Scope Restringido

Propósito técnico: Identificar el calendario comercial del usuario autenticado y gestionar los metadatos de contacto mediante extendedProperties.shared (donde se guarda el número de teléfono del cliente para habilitar el enlace directo a WhatsApp en la notificación).

04. Datos Procesados en Meta WhatsApp Cloud API (Graph API v21.0)

A través de la integración oficial con la API en la nube de WhatsApp de Meta, Seguiwats procesa exclusivamente:

  • ●
    Mensajes de voz (Audios OGG): Notas de voz enviadas voluntariamente por el vendedor. El audio se procesa en la memoria RAM del contenedor para transcripción (Speech-to-Text) y se purga de forma inmediata.
  • ●
    Mensajes de texto: Dictados directos de seguimientos comerciales enviados al número del asistente.
  • ●
    Número telefónico del vendedor: Utilizado como llave de autenticación para vincular el webhook al contenedor dedicado y calendario correspondiente.
  • ●
    Teléfono del prospecto: Extraído del mensaje y almacenado únicamente dentro del evento correspondiente en su Google Calendar.

05. Política de Retención y Eliminación ("Hard-Delete")

  • ✓
    Eventos cerrados o descartados: Cuando un seguimiento se marca como cerrado vía WhatsApp o directamente en Google Calendar, el evento se borra de manera definitiva (hard-delete) sin mantener réplicas.
  • ✓
    Logs de ejecución n8n: Se purgan automáticamente tras un período máximo de 72 horas para diagnóstico técnico y control de errores.
  • ✓
    Revocación inmediata: Si decide cancelar el servicio, las credenciales OAuth se eliminan y destruyen del contenedor.

06. Garantías Absolutas de No Comercialización y Cero Entrenamiento IA

Establecemos de manera explícita e irrevocable las siguientes garantías:

🚫 CERO Venta de Datos

Sus datos, contactos o contenido jamás serán comercializados, cedidos ni transferidos a intermediarios o agencias publicitarias.

🚫 CERO Entrenamiento de LLMs

Ninguna nota de voz, transcripción o dato recibido se utilizará para entrenar o ajustar modelos de IA generalistas ni propios ni de terceros.

07. Seguridad de Infraestructura y Aislamiento Multi-Tenant

  • ●
    Cada organización cliente opera en un contenedor Docker n8n independiente con volumen cifrado propio.
  • ●
    Cifrado obligatorio de todo el tráfico entrante y saliente mediante TLS 1.3 gestionado por Traefik v3.3.
  • ●
    Cortafuegos UFW endurecido que bloquea cualquier acceso no autorizado a nivel de kernel.
